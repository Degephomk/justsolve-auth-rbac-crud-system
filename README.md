# JustSolve — Authentication, RBAC & CRUD System

A full-stack project management application built with **Laravel 12** and **Angular 20**, featuring token-based authentication, role-based access control, and project management.

## Features
- User registration and authentication with Laravel Sanctum
- Role-based access control (Admin/User)
- Create, read, update, and delete projects
- Project status management: `open`, `closed`, and `paused`
- Request validation and authorization policies
- Activity logging with Eloquent Observers

## Tech Stack
- **Backend:** Laravel 12, PHP 8.3, Sanctum, SQLite
- **Frontend:** Angular 20, TypeScript, Angular Material

## Project Structure
- `backend/` — Laravel REST API
- `frontend/` — Angular web application

## Getting Started
Install backend dependencies with Composer and frontend dependencies with npm. Configure the backend environment, initialize its database, and set the frontend API URL to your Laravel server.
